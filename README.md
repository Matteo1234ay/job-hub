# Job Hub

Personal, zero-mandatory-cost job discovery dashboard for social/content/video roles around Torino and relevant remote opportunities.

## Privacy
The public feed contains job metadata only. Application tracking lives in browser localStorage. No analytics, cookies, account system, CV or email data are used by the frontend.

## Run
`pip install -r requirements.txt && python -m src.jobhub.run`

## Tests
`python -m pytest -q`
