# Job Hub Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Build a free, privacy-safe Job Hub that collects and ranks relevant jobs around Torino/Collegno/Rivoli every morning, shows them in a static dashboard, and lets the user track applications locally without publishing sensitive data.

**Architecture:** A Python collector runs in GitHub Actions on a daily schedule and writes only public job metadata to `public/data/jobs.json`. A static HTML/CSS/JS dashboard reads that file and stores application state exclusively in browser `localStorage`, with import/export backup. Source adapters are modular and failures are isolated. No Gmail, CV, email, tokens, or private application history are committed.

**Tech Stack:** Python 3.12 standard library + `requests`, pytest, vanilla HTML/CSS/JS, GitHub Actions, GitHub Pages.

**Spec:** Google Doc `Job Hub — Specifica di progetto` (file id `159K5VLkaE2QszK1-KdceSKC2unC1BUPdUPPVfdEIWws`).

## Global Constraints

- Do not modify `study-hub-v3`.
- No mandatory paid services or APIs.
- Public repository must never contain email content, CVs, credentials, OAuth tokens, application notes, or personally sensitive data.
- Daily search targets Torino, Collegno, Rivoli and nearby municipalities with default 25 km radius.
- Prefer official or credible sources; never bypass login, CAPTCHA, or technical protections.
- Applied jobs must not reappear as new in the local dashboard state.
- Source failure must not stop the rest of the run.
- All matching and verification decisions must be explainable.
